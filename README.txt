AI-Based Spam Message Detection System
========================================

1. Open this folder in VS Code.

2. Open Terminal in this folder.

3. Install required libraries:
   python -m pip install -r requirements.txt

4. Train the model:
   python train_model.py

5. Start the web application:
   python app.py

6. Open the local address shown in the terminal, usually:
   http://127.0.0.1:5000

Important:
- The included dataset is only a small starter dataset for development/testing.
- For the final college project, replace it with a larger public SMS spam dataset and report the actual test accuracy.
